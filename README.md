This project focuses on analyzing COVID-19 data using SQL to uncover trends, insights, and key metrics related to the pandemic's global impact. The goal is to demonstrate data analysis and querying skills using real-world datasets.

The COVID-19 SQL Project involves cleaning, transforming, and analyzing COVID case data using SQL queries. It covers important questions such as:
1. Total cases vs. total deaths per country
2. Countries with the highest infection rates
3. Mortality rate calculations
4. Infection and death trends over time
5. Vaccination progress globally
